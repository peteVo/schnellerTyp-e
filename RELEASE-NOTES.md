schnellerTyp-e 0.1.0 — first Windows build.

**Download `schnellerTyp-e-0.1.0-windows-x64.zip`, unzip it anywhere, run
`schnellerTyp-e.exe`.** Nothing to install. Read `READ-ME-FIRST.txt` inside if
Windows shows a blue "Windows protected your PC" box — that is SmartScreen not
recognising a new program, and the way past it is *More info* → *Run anyway*.

**German.** `ae → ä`, `oe → ö`, `ue → ü`, `ss → ß`, with a dictionary that knows
`Dauer`, `Duell`, `Wasser` and `aussehen` are not umlauts — and that corrects
itself as you keep typing, so `duell` stays put while `duester` still becomes
`düster`.

**Vietnamese.** Telex and VNI, with free tone marking, correct tone placement,
spelling check and auto-restore.

**Switching.** Tap **Ctrl + Shift** and let go to step German → Vietnamese →
… → Off. Other shortcuts are untouched: pressing any other key while the
modifiers are held cancels it, so Ctrl+Shift+T still reopens your browser tab.
The tray icon does the same job with the mouse.

**Custom rules.** A JSON file in the config folder adds a language or a set of
text expansions without recompiling. See `BUILD.md`.

Requires 64-bit Windows 10 or 11. Unsigned; see the note above.
